# Test fonts

`Cantarell-VF.otf` is the variable Cantarell font, version 0.301, unmodified as Fedora packages it in `abattis-cantarell-vf-fonts`. `ttf-typography` uses it for its weight axis from 100 to 800, its named instances and its proportional figures with a `tnum` feature. No release ships it.
